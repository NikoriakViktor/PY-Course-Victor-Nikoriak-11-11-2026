# GitHub

Усе, що стосується роботи з GitHub у цьому курсі.

- [SSH-ключі](ssh_keys.md) — як згенерувати ключ і підключити його до GitHub, щоб не вводити пароль щоразу.
- [Fork і Clone](fork_and_clone.md) — як отримати свою копію репозиторію курсу та клонувати її в PyCharm.
- [Pull Request](pull_request.md) — детальна покрокова інструкція зі скриншотами: як здати домашнє завдання через PR.
- [Профіль: README-візитівка](profile_readme.md) — спеціальний репозиторій з назвою, як твій логін: його README стає візитівкою на сторінці `github.com/<логін>`.
- [Як створити свій репозиторій](create_repository.md) — власний (не fork) репозиторій для капстоуна чи портфоліо, два реалістичні сценарії.
