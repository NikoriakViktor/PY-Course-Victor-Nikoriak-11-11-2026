Registry

Docker Hub · ghcr.io
Натискай → і простеж шлях однієї команди.
1. Ти пишеш docker run myapi:v1. CLI нічого не запускає — він лише надсилає запит.

3. Образу немає? Daemon сам робить pull із registry — і лише тоді запускає.

// 02 кеш шарів

Стабільне → мінливе

Ти це вже перевірив: залежності копіюємо до коду — і pip install береться з кешу.

# 03 multi-stage: зібрали в одному образі, запускаємо в іншому FROM python:3.12-slim AS builder WORKDIR /build COPY requirements.txt . RUN pip install --prefix=/install -r requirements.txt FROM python:3.12-slim RUN useradd --create-home app WORKDIR /app COPY --from=builder /install /usr/local COPY . . USER app CMD ["uvicorn", "main:app", "--host", "0.0.0.0"] # builder — з інструментами збірки, його викидаємо # фінальний образ — лише код і бібліотеки, не root
